## 🧭 راهنمای سریع / Quick guide

**فارسی**
1. کانفیگ مورد نظر را پیدا کن (جستجو یا فیلتر).
2. با دکمه **کپی** آن را در برنامه‌ات بچسبان.
3. اگر برنامه‌ات از لینک اشتراک پشتیبانی می‌کند، دکمه **لینک اشتراک** را بزن و لینک را در برنامه اضافه کن. برنامه خودش فهرست را به‌روز نگه می‌دارد.
4. اگر کانفیگی کار نکرد، دکمه **گزارش خرابی** را بزن تا بررسی شود.

**English**
1. Find the configuration you want (search or filters).
2. Tap **Copy** and paste it into your app.
3. If your app supports subscriptions, tap **Subscription link** and add it to the app. The app keeps the list up to date.
4. If a configuration does not work, tap **Report broken** so it can be reviewed.

## ⚠️ نکات مهم / Important notes

- **وضعیت «در دسترس» یعنی پورت سرور پاسخ داد.** این تضمین نمی‌کند که کانفیگ از شبکه شما کار کند.
  *"Reachable" only means the server port answered. It does not guarantee the configuration works on your network.*
- **زمان پاسخ از سمت سرور اندازه‌گیری می‌شود**، نه از دستگاه شما. برای مقایسه سرورها مفید است، نه برای پیش‌بینی سرعت شما.
  *Response times are measured from the server, not your device.*
- **کشور تقریبی است** و بر اساس آدرس سرور تعیین می‌شود.
  *The country is an estimate.*
